# Что было создано

## Обзор
Создан AI-агент на Python, который работает с базой данных ClickHouse через Claude API.

## Созданные файлы

### 1. `clickhouse_agent.py` - Главная программа
Основной файл агента, который:
- Принимает запросы пользователя на естественном языке
- Генерирует SQL запросы для ClickHouse (но НЕ выполняет их автоматически)
- Выполняет SQL только после того, как пользователь введет команду "execute"
- Работает в интерактивном режиме

**Ключевые особенности:**
- Класс `ClickHouseAgent` инкапсулирует всю логику
- Метод `generate_sql()` - генерирует SQL без выполнения
- Метод `execute_sql()` - выполняет SQL по подтверждению
- Метод `interactive_mode()` - интерактивная работа с пользователем

### 2. `config.yaml` - Конфигурация
Содержит:
- Параметры подключения к ClickHouse (хост, порт, логин, пароль, БД)
- Настройки Claude API (ключ, модель, температура)
- Используется реальная конфигурация из задания

⚠️ **Важно:** Этот файл добавлен в .gitignore для безопасности

### 3. `config.yaml.example` - Шаблон конфигурации
Пример конфигурации без реальных данных для документации

### 4. `requirements.txt` - Зависимости Python
Список необходимых библиотек:
- `claude-agent-sdk` - SDK для работы с Claude Agent
- `pyyaml` - для чтения YAML конфигурации

### 5. `README.md` - Подробная документация
Полная документация на русском языке:
- Описание возможностей
- Инструкции по установке
- Примеры использования
- Архитектурная диаграмма
- Решение проблем

### 6. `.gitignore` - Исключения Git
Настроен для исключения:
- Файлов Python (__pycache__, *.pyc)
- Виртуальных окружений
- Чувствительных данных (config.yaml, *.crt, *.key)
- Логов и временных файлов

## Как работает агент

```
Пользователь -> Вопрос на русском/английском
       ↓
Агент -> Claude API (анализ вопроса)
       ↓
Claude -> MCP ClickHouse (исследование схемы БД)
       ↓
Claude -> Генерация SQL запроса
       ↓
Агент -> Показывает SQL пользователю (БЕЗ выполнения!)
       ↓
Пользователь -> Проверяет SQL и вводит "execute"
       ↓
Агент -> Выполняет SQL через MCP
       ↓
Агент -> Показывает результаты
```

## Технологии

1. **Claude Agent SDK** - фреймворк от Anthropic для создания AI агентов
2. **ClickHouse MCP Server** - безопасный протокол для работы с ClickHouse
3. **Claude Sonnet 4.6** - языковая модель для понимания запросов
4. **Python asyncio** - асинхронная работа агента
5. **YAML** - формат конфигурации

## Безопасность

✅ **Реализованные меры:**
- SQL запросы НЕ выполняются автоматически
- Пользователь всегда видит SQL перед выполнением
- MCP сервер ограничивает доступ только к SELECT запросам
- Конфигурация с паролями исключена из Git

## Запуск

```bash
# Установка зависимостей
pip install -r requirements.txt

# Установка uv (для MCP сервера)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Запуск агента
python clickhouse_agent.py
```
